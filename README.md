# 待办事项 V2.0

原生 HTML + CSS + JavaScript 写的待办列表，没有使用任何框架。

## 功能

- 添加待办（回车或点「添加」，空输入和重复内容会被拦掉）
- 点条目文字切换「已完成」
- 点「删除」删掉这一条
- 「全部 / 未完成 / 已完成」三个筛选
- 「清除已完成」一次清掉所有已完成的
- 数据存在 localStorage，刷新后还在

## 数据流

状态只有一处：`todos` 数组。所有操作都走同一条路：

```
改数据（生成新数组） → save() → render()
```

添加用展开 `[...todos, 新任务]`，删除用 `filter`，切换用 `map` + 展开，
三个操作都不改原数组。

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖。
